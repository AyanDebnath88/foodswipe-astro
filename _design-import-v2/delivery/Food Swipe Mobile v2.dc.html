WHAT CHANGED FROM V1
photography is now the page, not content inside a card: hero runs edge to edge, 520px, no inset, no radius except the device
display face is Archivo 800 uppercase at -.025em — the sample set (Chipotle, Honest Greens) earns its hierarchy from weight and scale, not from ornament. Fraunces stays for editorial/dish titles only
bottom bar became a floating ink pill inset 20px, 26px above the home indicator — it hovers over content instead of walling it off
CTA is a pill with a terracotta circular arrow at the end; it reads as forward motion at a glance and gives the tap a 46px target inside a 58px row
data (LIVE, distance, price, time) is expressed as small caps chips in forest/gold, never as prose
scrim is a 3-stop gradient (.86 → .42 → 0) so 46px display type clears 4.5:1 on any photograph

SWIPE · SPEC
the card IS the screen: photo fills 390×844 behind a two-stop scrim, so the image reads at full size and the type still clears 4.5:1
cuisine title Archivo 800 56/.9 — one step larger than v1's 34px, because there is no longer a card frame competing with it
glass chips (16% white + 6px blur) carry round + vote state at the top; solid forest/gold chips carry data at the bottom. Two chip registers, never mixed
controls float over the image: like 80 · pass 68 · utility 56, centred on the thumb arc, 26px above the safe area
overlay stamp appears at 32px drag, opacity maps 0→1 over 32–120px, YES forest / NOPE terracotta
RESULTS · SPEC
results are a divided list, not a stack of cards — 1px #E7DDCF rules, 72px thumb, no shadow. Density beats decoration once the decision is made
chip row leads each row: mode (forest) → distance (gold) → disclosure (neutral). Sponsored is a neutral chip, never a coloured one
pickup/delivery is a segmented pair of pills, active = ink fill
the ink CTA pill floats at 26px; the list scrolls under it with 96px of bottom padding
MOTION

BUTTON HIERARCHY
ink pill + terracotta arrow = the single forward action on a screen. One per screen, always floating at 26px. #C4562F is icon-only (arrow circle, heart); any fill carrying a text label uses #B14A26 (4.9:1 with #FFF8F2)
solid terracotta = an action inside content flow (like, save) where no ink pill is present
tint #F1E9DD = secondary; outline = tertiary; ink text link = quaternary. Four levels, no more
on photography, buttons switch to #FFF8F2 fill with ink text — never a translucent primary
destructive stays #A6503A and only appears inside a confirm
PHOTOGRAPHY DIRECTION
overhead or 45° table shots, natural light, warm shadows, food filling ≥70% of frame. No white-background packshots
every full-bleed image needs 300px of usable scrim area at the bottom — brief photographers for negative space there
over-scrim contrast (measured at the lightest gradient stop): #FFF8F2 17.6:1 · #EBDFD2 14.1:1 · #E4D8CB 12.5:1 · #C6B8AB 9.5:1
4:3 source, WebP/AVIF, srcset 1x/2x, width+height declared, lazy below the fold
never place type on an unscrimmed photo; never scrim more than 60% of the image height
ACCESSIBILITY
targets: like 80 · pass 68 · utility 56 · nav 88×48 · arrow 46 inside a 58px pill — all ≥44pt, ≥8px apart
chips are 9.5px caps but never the only carrier: mode/distance also appear in the row's text line
every gesture has a button; every icon-only control has an aria-label
focus-visible 2px #C4562F at 2px offset, never animated; on dark surfaces it switches to #FFF8F2
on-photo type is tested against the darkest and lightest 10% of each image before shipping
